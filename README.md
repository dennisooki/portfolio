# Portfolio: Dennis Ooki Magolo

A high-performance personal portfolio site built with Next.js and Tailwind CSS.

## Tech Stack
- **Framework**: [Next.js 14+](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **vfx**: [Three.js](https://threejs.org/) + [React Three Fiber](https://r3f.docs.pmnd.rs/)

## Features
- **3D Hero**: Interactive particle field background.
- **Command Palette**: Press `Cmd+K` (or `Ctrl+K`) for global navigation and system checks.
- **Responsive**: Fluid layout across all devices.
- **Micro-interactions**: Custom cursor and physics-based UI elements.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
